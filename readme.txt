== Installation ==

Step 1: Download the Theme Package
- After purchasing the theme, download the complete theme package from your marketplace account or source.
- The downloaded ZIP file will include the following:
-- The main theme ZIP file (kerapy.zip)
-- A child theme ZIP file (kerapy-child.zip)
-- Documentation folder
-- Licensing information

Step 2: Upload the Theme

You can upload the theme using one of the two methods:

A. Using the WordPress Admin Panel
- Log in to your WordPress dashboard.
- Go to Appearance > Themes and click Add New.
- Click the Upload Theme button.
- Choose the kerapy.zip file from your computer.
- Click Install Now and wait for the installation to complete.
- Once installed, click Activate to enable the theme.

B. Using FTP
- Extract the kerapy.zip file on your computer.
- Use an FTP client (e.g., FileZilla) to connect to your server.
- Navigate to the /wp-content/themes/ directory.
- Upload the extracted kerapy folder to the themes directory.
- Log in to your WordPress dashboard and go to Appearance > Themes.
- Locate the KERAPY theme and click Activate.

Step 3: Install Required Plugins
After activating the theme, you’ll see a notification prompting you to install required plugins.

- Click Begin Installing Plugins.
- Select all the plugins listed and choose Install from the bulk actions dropdown.
- Once installation is complete, return to the plugins page and activate them.

Step 4: Import Demo Content (Optional)
To get your website up and running quickly, you can import the demo content provided with the theme.

- Navigate to Appearance > Import Demo Data in your WordPress dashboard.
- Choose the demo layout you want and click Import.
- Wait for the import process to finish. This may take a few minutes.
- Your website will now look like the demo, ready for customization.

Step 5: Activate the Child Theme (Optional)
For advanced customization, it’s recommended to use the child theme.

- Upload the kerapy-child.zip file following the same steps as above.
- Activate the child theme from Appearance > Themes.
- All customizations will now be stored in the child theme, preserving the original theme files during updates.
- Troubleshooting Theme Installation
- Missing style.css file: Ensure you are uploading the kerapy.zip file and not the complete theme package ZIP.

Installation failure: Check your hosting environment meets the theme requirements:
PHP version 7.4 or higher
Memory limit of at least 256MB
